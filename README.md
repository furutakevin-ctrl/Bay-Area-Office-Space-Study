# Bay Area Startup Office Space Study

This project researches whether seed funding differs between Bay Area startups using shared vs. private office spaces. It also explores whether documented prior founder experience is associated with funding outcomes.

## Dataset

The dataset is a random sample of 50 startups with offices located in the Bay Area (classified as being in the 9 counties: SF, San Mateo, Santa Clara, Alameda, Contra Costa, Solano, Napa, Sonoma, Marin). Each company contains the following data points:

- office-space type: shared or private
- seed funding amount and year
- founder-experience indicator: `1` if at least one founder had a documented prior startup, otherwise `0` for no documented evidence
- source and audit fields for reproducibility

PLEASE NOTE: This is a random sample. It does not establish associations for certain, it is merely just exploratory for possible further expansion.

## Main research question

Among the startups in this collected sample, is seed funding systematically different for companies using shared office space compared with companies using private office space? Is seed funding systematically different for companies with experienced founders compared to non-experienced founders?
